# 法務の索引

最終更新：2026-11-19。

この頁は、運営者のサイトとリポジトリの法的な枠組みを、この頁から辿るための索引です。
索引は案内であり、規程そのものではありません。
どの事柄も、リンク先の文が正です。
リンク先は、どれも各リポジトリの main の枝にあるファイルです。
検査は、リンク先のファイルがあることと、引いた節の名と句がリンク先にそのとおりにあることを確かめます。

条文の写しは、cpsbvbng26-dotcom の [statutes.json](https://github.com/cpsbvbng26-dotcom/cpsbvbng26-dotcom/blob/main/verification/statutes.json) にあります。

運営の決まりは、[運営の決まり](https://github.com/cpsbvbng26-dotcom/cpsbvbng26-dotcom/blob/main/docs/governance.md)の頁にあります。
