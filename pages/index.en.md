# Legal index

Last updated: 2026-11-25.

This page is an index from which the legal framework of the operator's sites and repositories can be followed.
The index is a guide, not a policy.
On every matter, the text linked to governs.
Every link points to a file on the main branch of its repository.
A check confirms that each linked file exists, and that each section name and phrase quoted occurs there as written.
