# 法令の整理

最終更新：2026-11-19。

この頁は、この入口について、運営者が法令をどう読んでいるかを書いたものです。
法的な助言でも保証でもありません。
弁護士の確認は受けていません。
引いた条文は、2026-11-19 に e-Gov 法令 API から取り寄せた現行の文です。
取り寄せた文は `verification/statutes-texts.json` にあります。
検査は、この頁と英語の頁に引いた句が、取り寄せた文にそのまま現れることを確かめます。
見張りの仕事は、週に一度同じ条を取り寄せ直し、記した文と違えば issue を開きます。
結論を出していないところは、出していないと書いています。
ほかのサイトの法令の読み方は、[法務の索引](./index.md)に挙げた、それぞれの記録にあります。

## 個人情報保護法

### 当たるかどうか

運営者が個人情報取扱事業者に当たるかどうかの結論は、この頁では出しません。
当たるものとして、次の条に沿って扱います。

### 利用目的

第17条第1項は「個人情報取扱事業者は、個人情報を取り扱うに当たっては、その利用の目的（以下「利用目的」という。）をできる限り特定しなければならない。」と定めます。
利用目的は、[個人情報の取り扱い](./privacy.md)の「利用の目的」に挙げています。

### 取得するときに示すこと

第21条第1項は「個人情報取扱事業者は、個人情報を取得した場合は、あらかじめその利用目的を公表している場合を除き、速やかに、その利用目的を、本人に通知し、又は公表しなければならない。」と定めます。
第21条第2項は、本人から直接書面に記載された個人情報を取得する場合に「あらかじめ、本人に対し、その利用目的を明示しなければならない。」と定めます。
同じ項は、書面に「電磁的記録を含む。」としています。
issue の様式とメールに書かれたものが、この項の書面に当たるかどうかの結論は、この頁では出しません。
当たるものとして、このリポジトリのために作った様式は、書く欄より前に利用目的を書いています。

### 漏えいなどが起きたとき

第26条第1項は、個人データの漏えいなどで委員会規則の定める事態が生じたときは「当該事態が生じた旨を個人情報保護委員会に報告しなければならない。」と定めます。
第26条第2項は、同じ場合に「本人に対し、個人情報保護委員会規則で定めるところにより、当該事態が生じた旨を通知しなければならない。」と定めます。
どの事態が委員会規則の定める事態に当たるかは、委員会規則の条を取り寄せていないので、この頁では結論を出しません。

### 第三者への提供

第27条第1項は「あらかじめ本人の同意を得ないで、個人データを第三者に提供してはならない。」と定めます。
issue は、書いた本人が GitHub の公開の場に出すものです。
運営者は、この公開を、運営者による第三者への提供とは扱いません。
この扱いが法令の上で正しいかどうかの結論は、この頁では出しません。

### 外国にある第三者

第28条第1項は「あらかじめ外国にある第三者への提供を認める旨の本人の同意を得なければならない。」と定めます。
第28条第2項は、同意を得ようとするときに「当該外国における個人情報の保護に関する制度、当該第三者が講ずる個人情報の保護のための措置その他当該本人に参考となるべき情報を当該本人に提供しなければならない。」と定めます。
運営者は、同意の欄に印のある issue の題と本文を、Claude（Anthropic、米国）に渡すことがあります。
運営者は、これを同条の提供として扱います。
その情報は、[個人情報の取り扱い](./privacy.md)の「外国にある第三者について知らせること」に書いています。
このリポジトリの様式は、どれも同意の欄にその頁へのリンクを置いています。
ただし、正本の写しである誤りの知らせの様式は、cpsbvbng26-dotcom の免責事項を指しています。
issue の中身が同条の「個人データ」に当たるかどうかの結論は、この頁では出しません。

### 本人が知り得る事柄と求め

第32条第1項は、保有個人データについて「本人の知り得る状態（本人の求めに応じて遅滞なく回答する場合を含む。）に置かなければならない。」と定めます。
その事項の初めは「当該個人情報取扱事業者の氏名又は名称及び住所」です。
運営者の氏名は、[個人情報の取り扱い](./privacy.md)に書いています。
住所は、届いた個人の情報の本人から求めがあれば、メールで遅滞なく答えます。
答えを受けるために、求めた人が自分の連絡先を公開する必要はありません。
第33条第1項は、本人が「電磁的記録の提供による方法その他の個人情報保護委員会規則で定める方法による開示を請求することができる。」と定めます。
第34条第1項は、保有個人データの内容が事実でないときに、本人が「当該保有個人データの内容の訂正、追加又は削除（以下この条において「訂正等」という。）を請求することができる。」と定めます。
第35条第1項は、本人が「当該保有個人データの利用の停止又は消去（以下この条において「利用停止等」という。）を請求することができる。」場合を定めます。
求めの手順は、[修正と削除の求め](./requests.md)にあります。

## 民法

第4条は「年齢十八歳をもって、成年とする。」と定めます。
第5条第1項は「未成年者が法律行為をするには、その法定代理人の同意を得なければならない。」と定めます。
第5条第2項は「前項の規定に反する法律行為は、取り消すことができる。」と定めます。
諮問委員への申し出と助言のどの行いが法律行為に当たるかの結論は、この頁では出しません。
運営者は、16 歳未満の人からの諮問委員への申し出を受けません。
18 歳未満の人からの申し出は、親または保護者の同意があるときに限って受けます。
この線は、research-collaboration の協力の条件と同じです。

## 労働基準法と労働契約法

労働基準法第9条は「この法律で「労働者」とは、職業の種類を問わず、事業又は事務所（以下「事業」という。）に使用される者で、賃金を支払われる者をいう。」と定めます。
労働基準法第11条は、賃金を「労働の対償として使用者が労働者に支払うすべてのものをいう。」と定めます。
労働契約法第6条は「労働契約は、労働者が使用者に使用されて労働し、使用者がこれに対して賃金を支払うことについて、労働者及び使用者が合意することによって成立する。」と定めます。
運営者は、諮問委員に、賃金も、ほかのどんな対価も払いません。
運営者は、助言の時間や場所を決めません。
運営者は、助言する人と労働契約を結びません。
これらの事実が、ある助言の関係を法令の上でどう位置づけるかの結論は、この頁では出しません。

## GitHub の利用規約

求めと申し出は GitHub の issue で受けます。
GitHub の利用規約 B.3 は「You must be age 13 or older.」と書いています。
GitHub の利用規約 D.4 は、issue を含む内容の使い方として「including by training AI Features, and for the purpose of training, developing, and improving artificial intelligence and machine learning models and technologies of our Affiliates」と書いています。
規約は、github/site-policy のコミット `166eb97e485b7de3cd5dbaf8c8d16e4310fda46c` の文から引きました。
運営者は、この規約を変えられません。
