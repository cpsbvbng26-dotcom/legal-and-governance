# 個人情報の取り扱い

最終更新：2026-11-19。

この頁は、このリポジトリ legal-and-governance の issue と、この入口に宛てたメールで届く個人情報の扱いを書いたものです。
ほかのリポジトリの扱いは、[法務の索引](./index.md)に挙げた、それぞれの頁によります。

## 取り扱う者

このリポジトリを運営するのは、GitHub のアカウント cpsbvbng26-dotcom の持ち主である個人、根本卓哉（Takuya Nemoto）です。
運営者の住所は公開していません。
住所は、届いた個人の情報の本人から求めがあれば、メールで遅滞なく答えます。
求め方は、[修正と削除の求め](./requests.md)の「公開の場で書けない求め」にあります。
法令の読み方は、[法令の整理](./law.md)の「個人情報保護法」にあります。

## 集めるもの

このリポジトリは、GitHub の issue に書かれたものと、運営者に届いたメールを扱います。
扱うのは、GitHub のアカウント名と、issue とメールに書かれたことです。
様式は、本名・住所・所属・連絡先を求めません。
諮問委員への申し出の様式だけは、ORCID iD を求めます。
病歴や心身の状態などの要配慮個人情報は求めません。
このリポジトリは、サイトも、cookie も、アクセス解析も持ちません。
GitHub の画面を見たときの記録は、GitHub が自身の方針で扱います。
メールの宛先は、Sophaxis と同じ運営者の受信箱です。
Sophaxis の[運営者と連絡先](https://github.com/cpsbvbng26-dotcom/sophaxis/blob/main/contact.ja.md)は、「メールは、運営者の iCloud メールの受信箱に届きます。日本の利用者に iCloud を提供するのは日本の会社 iTunes 株式会社で、米国の Apple Inc. がその会社に代わって取り扱うことがあります。」と書いています。
その受信箱を外国にある事業者が扱うことの読み方は、Sophaxis の[個人情報の取り扱いについて](https://github.com/cpsbvbng26-dotcom/sophaxis/blob/main/policies/privacy.ja.md)の「外国にある事業者の利用」にあります。

## 利用の目的

- 修正や削除などの求めに答え、そのリポジトリの手続きに沿って扱うこと。
- 誤りの知らせを確かめ、正誤表と訂正の記録に残すこと。
- 諮問委員への申し出を読み、公開の ORCID の記録で加われる人かを確かめ、答え、委員を選ぶこと。
- 委員の名と ORCID iD と申告を、本人が同意したあとに載せること。

運営者は、これらのほかには使いません。
このリポジトリのために作った様式は、書く欄より前に、この目的を書いています。

## 公開されること

issue は公開されます。
書いた本人が、GitHub の公開の場に出すものです。
GitHub（米国）は、その規約と方針に沿って、issue を保存し、表示します。
GitHub の利用規約は、issue を含む内容を、GitHub とその関連会社が AI の機能とモデルの学習に使うことを認めています。
その句は、[法令の整理](./law.md)の「GitHub の利用規約」に引いています。
運営者は、この使い方を止められません。

## 言語モデルに渡すこと

運営者は、このリポジトリの作業を Claude Code で行います。
同意の欄に印のある issue に限り、その題と本文を、Claude（Anthropic、米国）に渡すことがあります。
運営者は、これを個人情報保護法第28条の外国にある第三者への提供として扱います。
同意の欄の英語の文は「I consent to the operator giving the title and text of this issue to Claude (Anthropic, United States).」です。
このリポジトリのために作った様式では、印は任意です。
印が無い issue は、運営者が、Claude にもほかの言語モデルにも渡さずに扱います。
誤りの知らせの様式は、cpsbvbng26-dotcom の正本の写しで、その欄は必須です。
その様式で同意しないときは、誤りを運営者の [ORCID の記録](https://orcid.org/0009-0000-1406-0547)にあるメールアドレスで知らせることもできます。
issue のコメントとメールの中身は、言語モデルに渡しません。
同意は、その issue かメールで、いつでも撤回できます。
撤回のあとは、その issue を言語モデルに渡しません。
運営者が自分で開いた issue は、この限りではありません。
[免責事項](https://github.com/cpsbvbng26-dotcom/cpsbvbng26-dotcom/blob/main/DISCLAIMER.md)の「issue の中身と言語モデル」の節は、その範囲のリポジトリの様式について書いたものです。
このリポジトリの様式の扱いは、この頁によります。

## 外国にある第三者について知らせること

個人情報保護法第28条第2項が求める情報は、この節に書いています。
Anthropic は、米国の会社です。
米国の制度について、運営者は、個人情報保護委員会の[米国の制度についての情報](https://www.ppc.go.jp/enforcement/infoprovision/laws/offshore_report_america/)に拠ります。
委員会は、連邦について「包括的な法令は存在しない。」としています（[取り寄せた記録](https://github.com/cpsbvbng26-dotcom/sophaxis/blob/main/verification/sources-raw.json)）。
委員会は、米国が APEC の CBPR システムに加わった日を「2012年7月25日参加」と示しています（[取り寄せた記録](https://github.com/cpsbvbng26-dotcom/sophaxis/blob/main/verification/sources-raw.json)）。
委員会は、CBPR システムに加わっている国では、民間部門について「個人情報の保護について概ね我が国と同等の保護が期待できる」と説明しています（[取り寄せた記録](https://github.com/cpsbvbng26-dotcom/sophaxis/blob/main/verification/sources-raw.json)）。
Anthropic は、[プライバシーポリシー](https://www.anthropic.com/legal/privacy)で、「appropriate technical and organizational security measures designed to protect personal data from loss, misuse, and unauthorized access, disclosure, alteration, or destruction」を講じていると述べています（[取り寄せた記録](https://github.com/cpsbvbng26-dotcom/sophaxis/blob/main/verification/sources-raw.json)）。
これらの句は、Sophaxis の取り寄せの仕事が 2026-11-12 に読んだものです。
[免責事項](https://github.com/cpsbvbng26-dotcom/cpsbvbng26-dotcom/blob/main/DISCLAIMER.md)の「issue の中身と言語モデル」の節も、同じ句を同じ出どころから引いています。
Anthropic の句は、2026-11-19 にも同じ頁にあることを確かめました。
Anthropic が受け取った題と本文をどれだけ保ち、どう使うかは、運営者のアカウントの設定と Anthropic の規約によります。
その設定は、この頁では確かめていません。

## そのほかの第三者

運営者は、上のほかに、個人データを第三者に渡しません。
法令に基づく場合は別です。
諮問委員への申し出を確かめるために、運営者は、申し出た人の公開の ORCID の記録を読みます。
求めや知らせの中で、書いた人がほかの人のことを書くことがあります。
運営者は、それを、その求めや知らせに答えるためにだけ使います。
運営者が自分から第三者に個人データを求めることは、ORCID の記録を読むことのほかにはありません。

## 保存の期間

issue は、削除の求めがあるまで残します。
委員の名と申告は、委員でいるあいだ載せます。
委員が辞めたときは、名を外し、辞めた日を残します。
リポジトリの履歴と、ほかの人がすでに写したものには、記載が残ることがあります。
GitHub は、issue の動きを、通知を受け取る設定のアカウントに知らせます。
通知は、受け取る人の設定によって、issue の中身の写しを含む電子メールとしても届きます。
issue を消しても、すでに届いた通知の写しが消えるとは限りません。

## 安全のための措置

issue に書かれたものの写しは、GitHub が送る通知の電子メールと、同意のある issue の題と本文を Claude で扱った作業の記録に残ることがあります。
運営者は、そのほかの場所に、issue に書かれたものを集めません。
このリポジトリを変えられるのは、運営者の GitHub アカウントだけです。
変更は、公開の履歴にすべて残ります。

## 漏えいなどが起きたとき

個人データの漏えいなどで、法律が報告を求める事態が起きたときは、個人情報保護委員会に報告します。
本人には、本人が開いた issue か、本人から届いたメールの宛先で知らせます。
法令の読み方は、[法令の整理](./law.md)の「漏えいなどが起きたとき」にあります。

## 求め

自分についての記載は、訂正・削除・開示・利用停止を求めることができます。
費用はかかりません。
手順は[修正と削除の求め](./requests.md)にあります。
個人の情報を含む求めは、メールで受けます。
個人情報の扱いへの苦情も、同じ宛先で受けます。

## この方針の変更

変えたときは、この頁の日付を改めます。
過去の版は、公開の履歴に残ります。
